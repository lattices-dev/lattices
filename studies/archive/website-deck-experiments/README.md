# Website and deck experiment archive

These 30 PNGs were previously tracked at the repository root. They preserve
website concepts, poster explorations, and deck captures collected in commit
`45820808` on September 20, 2026. That commit date records their addition to
Git; it does not establish when each image was created.

The images are historical design material. They do not establish current
product behavior or an approved visual direction. Maintained product docs
remain in [docs](../../../docs/), and site assets remain in
[apps/site/public](../../../apps/site/public/).

All original filenames and image bytes are preserved. `test-3x3.png` is
byte-identical to `lattices-poster-industrial-3x3-fixed.png`; both names are
retained for historical context. No tracked text referenced these root image
paths when they were moved. The npm package file allowlist excludes this
archive.

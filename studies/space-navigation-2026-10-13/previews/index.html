What would this mean for the native app?

This study keeps the underlying desktop fixed while you browse. Only the preview selection and optional layout shapes change. Capturing images must never block navigation. A native implementation must distinguish a recent snapshot from live content, evict images when no longer needed, and handle missing previews gracefully. Browser smoothness does not establish native performance.

Only what this app exposes.

You see a window and an Export button. Accessibility, often shortened to AX, describes those controls to other tools.

That description is a tree. An app contains a window. The window contains controls, such as buttons.

An element can expose its role: Button; its title: Export; and a supported action: Press. A tool can ask the app to press it.

The app decides what it exposes. Some controls may be missing or incomplete. Tools need Accessibility permission to access and control other apps.

# Lattices website

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The learning and comparison section serves mid-level aspiring Mac power users, as confirmed on October 2, 2026. Readers are comfortable with their Mac and want to understand and choose automation tools.

## Product purpose

Lattices organizes Mac windows, terminal sessions, and workspaces through a native app and supporting CLI. The website explains these capabilities and provides learning resources about the surrounding macOS concepts.

## Capabilities and constraints

The existing website uses React, Vite, and static HTML export. Educational browser demonstrations use illustrative data; they cannot inspect the visitor's Mac accessibility tree. Action and Blink are separate products. Website work belongs in this checkout; native app installation and lifecycle remain in the native workspace.

## Evidence on hand

Repository documentation, official Apple references, and product documentation support the content. Search volumes, ranking potential, conversion rates, and hands-on competitor benchmarks have not been measured for this pilot.

## Product principles

- Teach one practical concept per page, with deeper technical detail available.
- Explain when each tool is a good fit, including competitors.
- Keep source review separate from hands-on testing.
- Generate pages from reviewed records with distinct substance.

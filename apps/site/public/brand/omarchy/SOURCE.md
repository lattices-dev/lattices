# Omarchy logo

`logo.svg` is an unmodified copy of the official Omarchy logo served at:
https://omarchy.org/brand/omarchy-logo.svg

Retrieved on 2026-10-17. The official homepage, https://omarchy.org/,
references this asset as its SVG icon. Original geometry and green fill
(`#9ece6a`) are preserved; the site renders it on a dark backing in both themes.

SHA-256: `4d00403ea7796c1fcd9a1574f807203f8d17f94d7c7fe90045963cf150346f70`

The mark identifies the homepage's Omarchy introduction and the announcement
of Lattices availability on Omarchy. It does not imply endorsement or affiliation. The adjacent visible text
names Omarchy, so the image is decorative for assistive technology.

Platform description: https://github.com/omacom/omarchy/blob/quattro/manual/01-welcome-to-omarchy.md
Lattices capabilities: https://github.com/lattices-dev/lattices/blob/main/apps/linux/README.md
Installer and requirements: https://github.com/lattices-dev/lattices/blob/main/docs/install-linux.md
The homepage install command follows this guide. Its publication requires the
Linux installer from PR #224 to be available on main.

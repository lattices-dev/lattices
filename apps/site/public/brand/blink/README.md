# Blink logo assets

Generated by `bun run brand` from `src/components/blink/BlinkMark.tsx`. Edit the component, not these files.

| File | Use |
| --- | --- |
| `blink-light.svg`, `blink-dark.svg` | The mark for light and dark backgrounds |
| `blink-{light,dark}-{size}.png` | The same, transparent, at 16, 24, 32, 48, 64, 80, 128, 256, 512, 1024 px |
| `blink-icon.svg`, `blink-icon-{size}.png` | The app icon on Apple's grid, on the dark tile |
| `blink-icon-light.svg`, `blink-icon-light-{size}.png` | The same on the white tile, the light appearance |
| `blink-favicon.svg` | Browser tab icon: the dark tile edge to edge |
| `blink-touch-icon.png` | 180 px home screen icon, square and opaque |

Theme names describe the intended background, so `light` is dark ink. The PNGs are proportional exports, not separately optically adjusted drawings.

A panel frame with two blocks stepping across it, on the Lattices grid: the frame’s outer edge sits on the 16-unit square and its stroke is the grid’s 1.2-unit gap. The front block, the note in hand, carries the accent. The page header draws the same component in `currentColor`, with the accent from `--logo-accent`.

## App icon

An 824 px tile in a 1024 canvas with continuous corners, shared by every Lattices product: the family's light ink `#101518` for the dark appearance and white for the light. The glyph's longer side spans 56% of the tile, as in every product icon. The favicon and touch icon keep the dark tile, drop the margin and grow the glyph 18%.

Measured glyph bounds in viewBox units: 1.992, 1.992, 16.016 × 16.016.

The app draws its icon from `products/blink/assets/AppIcon.icon`, an Icon Composer document with one flat layer per colour and both appearances, so the Dock follows the icon style set in System Settings. On macOS the export compiles it to `products/blink/assets/Assets.car`, which the app build copies into the bundle with `CFBundleIconName` `AppIcon`, and writes `products/blink/assets/AppIcon.icns` from the dark icon for the disk image. Before macOS 26 the system shows the light icon, which actool flattens into the car.

It also keeps `products/blink/assets/AppIcon.svg` in step with the icon.

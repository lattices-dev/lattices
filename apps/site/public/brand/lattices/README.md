# Lattices logo assets

Generated by `bun run brand` from `src/components/LatticesMark.tsx`. Edit the component, not these files.

| File | Use |
| --- | --- |
| `lattices-light.svg`, `lattices-dark.svg` | The mark for light and dark backgrounds |
| `lattices-{light,dark}-{size}.png` | The same, transparent, at 16, 24, 32, 48, 64, 80, 128, 256, 512, 1024 px |
| `lattices-icon.svg`, `lattices-icon-{size}.png` | The app icon on Apple's grid, on the dark tile |
| `lattices-icon-light.svg`, `lattices-icon-light-{size}.png` | The same on the white tile, the light appearance |
| `lattices-favicon.svg` | Browser tab icon: the dark tile edge to edge |
| `lattices-touch-icon.png` | 180 px home screen icon, square and opaque |

Theme names describe the intended background, so `light` is dark ink. The PNGs are proportional exports, not separately optically adjusted drawings.

A 3 × 3 grid with the left column and bottom row lit: the L. The centre carries the accent: the pointer, Action’s cursor with its tip in the crook of the L and its tail on the cell’s top and right edges. The `centre` prop swaps in another shape while Lattices does one job: `knob` to release, `sweep` to move, `bracket` for a session, `node` for live. `accent={false}` draws the centre as a plain dim cell. The site header draws the same component with `theme` unset, so it follows the `--logo-ink`, `--logo-dim` and `--logo-accent` tokens and their hover states.

`public/favicon.svg` is a copy of `lattices-favicon.svg`.

## App icon

An 824 px tile in a 1024 canvas with continuous corners, shared by every Lattices product: the family's light ink `#101518` for the dark appearance and white for the light. The glyph's longer side spans 56% of the tile, as in every product icon. The favicon and touch icon keep the dark tile, drop the margin and grow the glyph 18%.

Measured glyph bounds in viewBox units: 1.992, 1.992, 16.016 × 16.016.

The app draws its icon from `assets/AppIcon.icon`, an Icon Composer document with one flat layer per colour and both appearances, so the Dock follows the icon style set in System Settings. On macOS the export compiles it to `assets/Assets.car`, which the app build copies into the bundle with `CFBundleIconName` `AppIcon`, and writes `assets/AppIcon.icns` from the dark icon for the disk image. Before macOS 26 the system shows the light icon, which actool flattens into the car.

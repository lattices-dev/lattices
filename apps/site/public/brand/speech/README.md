# Speech logo assets

Generated by `bun run brand` from `src/components/SpeechMark.tsx`. Edit the component, not these files.

| File | Use |
| --- | --- |
| `speech-light.svg`, `speech-dark.svg` | The mark for light and dark backgrounds |
| `speech-{light,dark}-{size}.png` | The same, transparent, at 16, 24, 32, 48, 64, 80, 128, 256, 512, 1024 px |
| `speech-icon.svg`, `speech-icon-{size}.png` | The app icon on Apple's grid, on the dark tile |
| `speech-icon-light.svg`, `speech-icon-light-{size}.png` | The same on the white tile, the light appearance |
| `speech-favicon.svg` | Browser tab icon: the dark tile edge to edge |
| `speech-touch-icon.png` | 180 px home screen icon, square and opaque |

Theme names describe the intended background, so `light` is dark ink. The PNGs are proportional exports, not separately optically adjusted drawings.

Two waveform bars frozen at the playhead: the word just spoken in ink and the one sounding now in the accent, with the rest of the readout left out. Short then tall, the pair also draws a speaker. Each bar is a Lattices cell wide, the tall one a full column of the grid, so the glyph runs the 16-unit height and 10.27 units across, centred in the box. It uses the Lattices ink and has no dim.

## App icon

An 824 px tile in a 1024 canvas with continuous corners, shared by every Lattices product: the family's light ink `#101518` for the dark appearance and white for the light. The glyph's longer side spans 56% of the tile, as in every product icon. The favicon and touch icon keep the dark tile, drop the margin and grow the glyph 18%.

Measured glyph bounds in viewBox units: 4.863, 1.992, 10.273 × 16.016.

The app draws its icon from `products/voice/assets/AppIcon.icon`, an Icon Composer document with one flat layer per colour and both appearances, so the Dock follows the icon style set in System Settings. On macOS the export compiles it to `products/voice/assets/Assets.car`, which the app build copies into the bundle with `CFBundleIconName` `AppIcon`, and writes `products/voice/assets/AppIcon.icns` from the dark icon for the disk image. Before macOS 26 the system shows the light icon, which actool flattens into the car.
